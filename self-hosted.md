# maps.caving.dev
This is a self-hosted instance of Mergin Maps, which will hopefully get a lot of use on Caving expeditions next summer. GIS data management is notoriously difficult to manage, especially with lots of cavers who don't have funds for a professional option. 

# github.com/webrecorder/browsertrix-crawler
Browsertrix is a self-hosted web archival tool that, unlike tools like archive.is that archive a single page, collects a webpage and all pages linked to from the page. Due to its complexity the only official method of running it is on kubernetes.

# social.bigcavemaps.com
Self-hosted Mastodon instance

# cavepedia-v2
This is an in-progress upgrade from git.seaturtle.pw/pew/cavepedia, but with an upgraded search engine using vector embeddings instead of go's bleve engine. Unfortunately this was somewhat put on hold due to my colo provider getting evicted in September 2025. (protip: don't use the cheapest hosting possible!)
